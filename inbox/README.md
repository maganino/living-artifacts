# Inbox

Anything dropped here for Claude to learn from or work with: skills other people
wrote, templates, saved web pages, PDFs, exports, transcripts. Nothing in here is
read by code and nothing is final. It is triaged, not kept:

| It turns out to be | It goes to |
|---|---|
| A skill, or a rule about how to work | the PMOS repo, `skills/` (symlinked into `~/.claude/skills/`) |
| A general learning, framework or method | the PMOS repo, `knowledge/learnings/` |
| Data a script in this repo reads | `inputs/`, with a provenance row in `inputs/README.md` |
| A document people wrote or will read | `docs/` |
| Generated by a script | it never lands here, it lands in `output/` |

Same folder, same rules, in every repo. Leave the original here after triage so
the source can be checked, and say in the triage note where the copy went.
